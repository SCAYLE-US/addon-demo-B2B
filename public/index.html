SCAYLE Panel Demo Add-On

A micro-frontend module for the SCAYLE Panel. This deployment hosts the add-on bundle — it isn't meant to be viewed standalone.

Entry points

  • manifest.js — SystemJS module loaded by the host panel
  • manifest.json — Vite build manifest

Usage

Register this URL as an add-on inside the SCAYLE Panel. The host loads manifest.js at runtime via single-spa and mounts the Vue app into a shadow-DOM container.
